# 三层连连看选题法（linkup-topic-generator）

一个**纯推理的内容选题生成器**：你只给一个中心词（行业 / 账号 / 产品），它自动跑「中心 → 行业相关词 → 人群+场景」三层连连看，三点一线批量出选题；每条重点题再附公众号 / 小红书 / 抖音三个标题变体 + 一句"为什么可能爆"。

## 特点

- 不联网、不采数据、不写脚本
- 不焊死任何行业或人设，换中心词即给任意行业出题，代运营也能直接用
- 适用：起号铺选题库、代运营交付、今天不知道拍什么

## 怎么用

在 WorkBuddy 对话里直接说：

> 用连连看给我出一批选题，中心词是「游泳馆」

或：

> 换个行业出题，中心词「二奢」

它会自动跑三层：

- **中心格** = 你填的行业词
- **第 2 圈** = 行业相关词（自动联想，也可手动加）
- **第 3 圈** = 人群 + 场景（内置通用高频清单，可替换成你行业的）

然后三点一线批量组合，一次给你一批选题（默认 15–30 条，能加量）。

## 出什么

以中心词「游泳馆」为例，会产出如：

- 小朋友学游泳是先学自由泳还是先学蛙泳？
- 成人想学蝶泳多久能学会？
- 为什么我们泳馆在社区开了五年？
- 游泳换气总呛水怎么办？

每条重点题附三个平台标题变体 + 爆点判断。

## 边界（写进 skill，谁用都成立）

- 不编经历、不编案例：选题不依赖你本人故事，缺数据标"可找真实数据佐证"
- 不替你定"做谁的生意"：人群未指定给通用高频，标注可替换
- "为什么可能爆"是方法推断，不是"必火"承诺，数字不许凭空编
